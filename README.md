# 🚀 Premium Next.js SaaS Admin Dashboard Template

A highly polished, production-ready Admin Dashboard Template built for modern SaaS applications. Designed with aesthetics and developer experience in mind, this template provides a seamless starting point for your next big project.

## ✨ Features

- **Next.js 16.2 (App Router)**: Utilizing the latest React features and Server Components.
- **Tailwind CSS v4**: Strict, premium dark-mode-first design system built completely in `globals.css` using the new `@theme` configuration.
- **Beautiful UI Components**: Reusable, clean, and accessible UI components (Cards, Tables, Badges, Buttons).
- **Interactive Analytics**: Sleek, fully responsive Recharts integration for revenue tracking.
- **Client-Side Data Tables**: Highly functional user management with real-time search, filtering, and sorting.
- **TypeScript**: End-to-end type safety for a reliable developer experience.
- **Lucide Icons**: Crisp, customizable vector icons.

## 🛠️ Tech Stack

- **Framework:** Next.js (React)
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Charts:** Recharts
- **Utilities:** clsx, tailwind-merge

## ⚡ How to Use / Quick Start

Get the dashboard up and running on your local machine in seconds!

### 1. Clone the repository
```bash
git clone https://github.com/Pavly17/nextjs-saas-admin-template.git
cd nextjs-saas-admin-template
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

### 4. View the Dashboard
Open [http://localhost:3000](http://localhost:3000) in your browser. You will immediately see the dashboard running locally!

## 📁 Project Structure

- `/src/app` - Next.js App Router pages (Overview, Users, Content).
- `/src/components/ui` - Reusable UI components.
- `/src/components/layout` - Global layout components (Sidebar, Topbar).
- `/src/components/dashboard` - Dashboard-specific components (Charts).
- `/src/lib` - Utility functions and decoupled mock data.
